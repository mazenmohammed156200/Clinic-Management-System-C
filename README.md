# Clinic Management System (C Language)

A console-based Clinic Management System built using C language, implementing singly linked lists, dynamic memory allocation, and data structure concepts.

## Features
- **Admin Mode:**
  - Add / Edit patient records (Name, Age, Gender, ID)
  - Reserve / Cancel doctor slots
- **User Mode:**
  - View patient information
  - View today's doctor appointments

## Requirements & Compilation
To compile the project using GCC:
```bash
gcc C_main.c C_Program.c -o clinic_system
./clinic_system
